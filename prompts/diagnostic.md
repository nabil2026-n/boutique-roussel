# Modèle de prompt — Diagnostic d'un ticket

## [SYMPTOME]

Décrire le symptôme observé.

## [ETAPES]

Décrire les étapes permettant de reproduire le problème.

## [ATTENDU]

Décrire le résultat attendu.

## [CODE_CONCERNE]

Indiquer les fichiers, fonctions ou extraits de code à examiner, s'ils sont connus.

Analyse le problème avant toute correction. Propose plusieurs hypothèses expliquant le comportement et classe-les par probabilité. Pour chaque hypothèse, indique les fichiers, les fonctions et les extraits de code concernés, ainsi que les éléments qui la soutiennent ou l'écartent. Propose des vérifications concrètes dans le navigateur, notamment avec la console, des points d'arrêt et l'inspection du stockage lorsque c'est pertinent. Distingue clairement les hypothèses des faits vérifiés. Ne modifie aucun fichier et ne propose aucune correction avant validation du diagnostic.
